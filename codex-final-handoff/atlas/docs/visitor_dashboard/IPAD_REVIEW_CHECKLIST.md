# iPad review checklist

- Test the actual 9.79-inch iPad in landscape and Safari standalone mode.
- Confirm every touch target is at least 44x44 CSS pixels.
- Confirm the name keyboard and numeric age keypad do not obscure Continue.
- Complete the flow with touch, external keyboard, VoiceOver, and Switch
  Control.
- Verify visible focus, heading order, form-error association, and polite
  announcements.
- Enable Reduce Motion and confirm every auto transition has a manual path.
- Rotate away from and back to landscape without losing control access.
- Verify safe-area insets and dynamic viewport sizing.
- Select Arabic preview and inspect reading/focus order, not only alignment.
- Disconnect and reconnect Wi-Fi during onboarding; selections stay in memory
  but Start remains blocked until transfer is confirmed.
- Verify help, acknowledgment, in-use lock, thank-you, and automatic reset.
- Confirm no browser history, storage, or cached API response retains profile
  information after reset.
