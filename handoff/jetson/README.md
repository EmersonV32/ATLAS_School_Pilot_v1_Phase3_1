# Jetson continuity

Use these documents in this order:

1. [`REBUILD_FROM_FRESH_FLASH.md`](REBUILD_FROM_FRESH_FLASH.md) for disaster
   recovery or a replacement device.
2. [`OPERATIONS_MANUAL.md`](OPERATIONS_MANUAL.md) for normal startup, stop,
   service, and diagnostic procedures.
3. [`JETSON_ATLAS_QUICK_COMMANDS.txt`](JETSON_ATLAS_QUICK_COMMANDS.txt) for a
   concise command reference.

`ATLAS_JETSON_NX_SETUP_LOG.md`, `NX_FLASH_NOTES.txt`, and the dated snapshot are
historical device evidence. Verify their assumptions against the current
device before repeating low-level flash or repair steps.
