# ATLAS Master Competition Checklist

Checkboxes should be closed only when evidence or a confirmation link is
recorded.

## Registration And Eligibility

- [ ] Confirm the official Future Innovators age group.
- [ ] Confirm qualification and team slot with WRO Canada / Zone01.
- [ ] Confirm every registered participant, coach, and supporter before the
      addition deadline.
- [ ] Obtain the international submission deadline and upload instructions.
- [ ] Sign the WRO Ethics Code using the organizer's required process.
- [ ] Obtain a written ruling on borrowed compute for model training.
- [ ] Maintain team-authorship evidence and the AI-use register.

## Robot And Software

- [ ] Finish the headset/camera mechanical mount and protective case.
- [ ] Finish battery, cooling, cable management, and strain relief.
- [ ] Validate the new artwork model on images not used for training.
- [ ] Measure per-class precision, recall, false positives, and Jetson FPS.
- [ ] Test the complete visitor onboarding and admin controls.
- [ ] Test all advertised languages end to end.
- [ ] Test Shokz and speaker modes after disconnect/reconnect.
- [ ] Test manual capture and artwork auto-prompt behavior.
- [ ] Test conversation context over multiple turns.
- [ ] Confirm the service stays active until manually stopped.
- [ ] Complete an eight-hour thermal and reliability test.
- [ ] Freeze and tag the competition release.

## Evidence And Research

- [ ] Interview at least one museum professional.
- [ ] Test with target visitors across ages and familiarity levels.
- [ ] Include accessibility testing where possible.
- [ ] Record test method, sample size, failures, and measurable results.
- [ ] Create a competitor comparison.
- [ ] Complete bill of materials and unit cost.
- [ ] Explain revenue, maintenance, museum setup, partners, and scaling.
- [ ] Document artwork-image and dataset provenance.
- [ ] Document privacy, retention, cloud use, safety, and limitations.

## Report, Video, And Presentation

- [ ] Produce the English report within all page and file-size limits.
- [ ] Add the AI-use disclosure and source list.
- [ ] Produce the 90-second English operating video.
- [ ] Prepare four printed reports.
- [ ] Prepare 30-second, 2-minute, and 5-minute explanations.
- [ ] Rehearse the 5-minute judged presentation without overrunning.
- [ ] Give every team member technical and business questions.
- [ ] Run at least three adversarial mock judging sessions.
- [ ] Prepare a truthful degraded-mode explanation and recorded proof.

## Booth

- [ ] Build and test an exact 2 m x 2 m x 2 m mock booth.
- [ ] Keep the table, ATLAS, team, and decoration within its boundaries.
- [ ] Confirm poster dimensions and wall attachment rules.
- [ ] Confirm power, Wi-Fi, setup access, and overnight storage.
- [ ] Make posters packable and duplicate their print-ready files.
- [ ] Install cable covers and secure the equipment.
- [ ] Pack a visitor QR code and a no-internet information fallback.
- [ ] Perform one timed booth assembly and disassembly.

## Travel

- [ ] Confirm final event and arrival schedule with the organizer.
- [ ] Book flights and accommodation with change protection where possible.
- [ ] Verify passport/ESTA requirements for every traveller.
- [ ] Prepare original consent letters and supporting documents for minors.
- [ ] Purchase travel health and equipment insurance.
- [ ] Register the trip with the Government of Canada.
- [ ] Arrange airport-to-hotel transport for people and equipment.
- [ ] Complete the equipment manifest, photos, and serial-number list.
- [ ] Decide whether BSF407 or an ATA Carnet is appropriate.
- [ ] Verify every battery's Wh rating and airline approval.
- [ ] Assign every critical component to a carry-on owner.
- [ ] Weigh and measure every finished bag.

## Backups And Recovery

- [ ] Create and verify a Jetson disk image or equivalent restore image.
- [ ] Verify a clean rebuild using the GitHub handoff documentation.
- [ ] Carry two encrypted local backups in separate bags.
- [ ] Maintain one cloud backup with secrets stored separately.
- [ ] Print the short recovery checklist and essential contacts.
- [ ] Test every spare cable, adapter, camera, and audio device.
- [ ] Run every failure drill in `templates/FAILURE_DRILL_LOG.csv`.
